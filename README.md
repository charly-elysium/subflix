# 🎬 SUBFLIX

**Sistema profesional de gestión de cuentas streaming**

SUBFLIX es una plataforma web diseñada para administrar y comercializar
servicios de suscripción digital (Netflix, Disney+, Spotify, IPTV, etc).
Permite a los clientes consultar sus accesos y vencimientos mientras el
administrador controla cuentas, pagos y renovaciones desde un panel
centralizado.

## 🧠 ¿Qué problema resuelve?

Quienes venden servicios streaming suelen manejar:

-   Usuarios en WhatsApp
-   Contraseñas en notas
-   Pagos sin control
-   Vencimientos olvidados
-   Clientes preguntando accesos constantemente

SUBFLIX centraliza todo en un solo sistema.

## 👤 Panel Cliente

-   Visualización de servicios activos
-   Acceso a usuario, contraseña y PIN
-   Alertas de vencimiento
-   Avisos y promociones
-   Catálogo de plataformas disponibles
-   Solicitud directa vía WhatsApp
-   Cambio obligatorio de contraseña en primer acceso
-   Compatible con celular, tablet y PC

## 🛠️ Panel Administrador

-   CRUD de clientes
-   Generación automática de usuario y contraseña
-   Envío de accesos por WhatsApp
-   Gestión de cuentas streaming
-   Asignación de perfiles
-   Control de suscripciones
-   Registro de pagos y renovaciones
-   Gestión de promociones
-   Gestión de plataformas

## 🔐 Seguridad

-   Sesiones protegidas
-   Bloqueo de acceso a carpetas internas
-   Forzado de cambio de contraseña
-   Rutas amigables protegidas (.htaccess)
-   Preparado para autenticación por token (API móvil)

## 🧱 Tecnologías

-   PHP 8+
-   MySQL / MariaDB
-   Bootstrap 5
-   Apache (.htaccess routing)
-   REST API preparada para App móvil

## 📱 Roadmap

## 🚀 Instalación

1.  Clonar repositorio
2.  Importar `database.sql`
3.  Configurar `app/config/db.php`
4.  Apuntar dominio a `/public`
5.  Acceder a `/login`

## ⚙️ Requisitos

-   PHP 8.0+
-   MySQL 5.7+ / MariaDB
-   Apache con mod_rewrite

## 🎯 Objetivo

SUBFLIX está diseñado para negocios reales que venden suscripciones
digitales y requieren control organizado de clientes, pagos y accesos.
